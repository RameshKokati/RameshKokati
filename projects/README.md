## Projects

### [GitHub API vs MCP](https://github.com/RameshKokati/github-api-vs-mcp)

Three ways to access open GitHub issues: call GitHub's REST API directly from Python, expose that operation through a FastAPI web service, and make it available to an AI client through an MCP server.

The comparison uses the same underlying GitHub operation to show what each layer does and how the invocation differs.
